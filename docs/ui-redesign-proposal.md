## 二、设计目标与原则

1. **壁纸是画布，内容是主角。** 每日 Bing 壁纸是全站情绪基调，玻璃材质只做"承托"，不抢戏：降低玻璃高光与描边噪声，把对比度让给文字和数据。
2. **一个屏幕一个焦点。** 每个页面有且只有一个主视觉区（仪表盘是"今日焦点"，路线图是当前阶段，招花是职位流），其余信息退为次级。
3. **色板克制。** 全站色相只允许出现：靛蓝（主）、青（辅）、绿/橙/红（语义）。图表不再各自配色。
4. **符合既有习惯。** 保留用户已熟悉的布局骨架（左侧导航 + 内容区、底部 Tab），改版是"进化"不是"革命"，老用户零学习成本。
5. **真实可算。** 所有 KPI 与图表必须来自现有 API 或可直接扩展的查询，不设计伪指标。

> **逐节冲突提示（v1.2 评审补充）**：§2 原则 1、§3.1 浅色色板、§3.5 三档主题、§5.4 设置页中「全站壁纸」「跟随壁纸」等表述均为 v1.1 基线。v1.2（§十一）已把壁纸收敛为「仅专注页」、并将浅色视觉切换为油画系列、主题三档改为「浅色/深色/跟随系统」。凡与 §十一 冲突处一律以 §十一 为准。

## 三、设计系统升级

### 3.1 色板（修订版）

在现有 tokens 基础上收敛与补全：

| Token | 浅色模式 | 深色模式 | 用途 |
|---|---|---|---|
| `background` | `#f6f7fa` | `#0d0d12` | 页面底（壁纸缺席时的兜底） |
| `primary` | `#4f46e5` | `#818cf8` | 主行动、选中态、进度 |
| `primary-foreground` | `#ffffff` | `#0d0d12` | 主色上的文字 |
| `accent` | `#0ea5e9` | `#38bdf8` | 次级强调、链接、图表辅色 |
| `success` | `#16a34a` | `#4ade80` | 完成、已掌握 |
| `warning` | `#d97706` | `#fbbf24` | 提醒、临期 |
| `danger` | `#dc2626` | `#f87171` | 删除、逾期 |
| `text` | `#18181b` | `#f4f4f5` | 正文 |
| `text-muted` | `rgba(24,24,27,.62)` | `rgba(244,244,245,.66)` | 次要文字（提升现有 .78/.78 → 满足对比度同时保留层次） |

**图表色板映射规则（新增，硬性）**：

```
序列数据（多系列）  → primary 系梯度：#4f46e5 → #6366f1 → #818cf8 → #0ea5e9 → #38bdf8
状态数据           → success / warning / danger / neutral(#a1a1aa)
"我的"数据         → 一律 accent 青，与市场/目标数据（primary 靛蓝）形成固定对比
背景网格/坐标轴     → rgba(text, 0.08) / rgba(text, 0.35)，禁用彩色网格
```

禁止新增任何不在上表中的色相（现有 emerald/violet/amber/pink 彩虹板废弃）。

> **v1.2 提示**：上表为 v1.1 基线色板（透明玻璃体系）。v1.2 的浅色（默认）改用 §11.3「油画系列」tokens，深色档继续沿用上表深色列；两侧都应落在「tokens 单一事实源」里（§9）。

### 3.2 圆角统一规范

| 场景 | 值 | 说明 |
|---|---|---|
| 按钮、输入框、小徽章 | `md` 12px | 交互控件 |
| 卡片、弹窗、图表容器 | `lg` 16px | 容器层（.glass、Card 统一到此值） |
| 页面级大容器、底部抽屉 | `2xl` 28px | 仅移动端抽屉/全屏浮层 |
| 头像、开关、进度点 | `full` | — |
| 图表内部单元格（treemap 等） | `sm` 8px | 容器内最小单位 |

废弃散落在组件里的 `rounded-[10px]`、`rounded-lg` 等裸值，全部引用 token。

### 3.3 三级玻璃体系

将目前单一 `.glass` 拆为三个层级，参数明确：

| 层级 | 用途 | 背景（浅色/深色） | blur | 边框 | 阴影 |
|---|---|---|---|---|---|
| **Glass-1 导航层** | 侧边栏、顶栏、移动端 Tab | `rgba(255,255,255,.55)` / `rgba(13,13,18,.62)` | 24px sat 1.6 | `rgba(255,255,255,.35)` | `0 4px 16px rgba(0,0,0,.06)` |
| **Glass-2 卡片层** | 内容卡片、图表容器 | `rgba(255,255,255,.42)` / `rgba(13,13,18,.48)` | 16px sat 1.4 | `rgba(255,255,255,.25)` | `0 8px 24px rgba(0,0,0,.08)` |
| **Glass-3 浮层** | 弹窗、下拉、Toast | `rgba(255,255,255,.82)` / `rgba(20,20,26,.88)` | 32px sat 1.8 | `rgba(255,255,255,.4)` | `0 16px 48px rgba(0,0,0,.16)` |

原则：**层级越高越实**。浮层必须接近不透明以保证内容可读；卡片保留通透感；导航介于两者之间。去除现有 `.glass::before/::after` 的径向光泽+内圈描边双重高光（视觉噪声来源），只保留 Glass-1 的顶部 1px 内高光。

### 3.4 字体阶与间距

- 字体阶沿用 tokens（12/14/16/18/20/24/30/36），新增两条使用规则：页面主标题 `2xl(24)/bold`、区块标题 `lg(18)/semibold`、正文 `sm(14)`、辅助 `xs(12)`；数字 KPI 用 `tabular-nums` + JetBrains Mono 备选。
- 间距栅格 8pt：卡片内边距 `24`，卡片间距 `16`（桌面）/ `12`（移动），页面左右留白 `32`（桌面）/ `16`（移动）。
- 内容区最大宽度 `1200px` 居中（与后台方案一致）。

### 3.5 明暗模式机制（解决现状问题 7）

设置页提供显式三档：**浅色 / 深色 / 跟随壁纸（默认）**。

- 跟随壁纸 = 现有 bg-dark 亮度检测逻辑，但对用户可见：设置页显示当前判定结果（"当前：深色"）。
- 手动选择浅色/深色时，壁纸亮度自动逻辑停用，避免两套机制打架。
- 落库 key：`ui.theme = light | dark | auto`（沿用后台方案的 settings 命名规范）。

> **v1.2 提示**：§3.5 的「跟随壁纸（默认）」在 v1.2 已改为「跟随系统（默认）」，且 `auto` 的语义从「壁纸亮度自动」变为「`prefers-color-scheme` 跟随系统」。`ui.theme` 枚举值不变（仍是 `light | dark | auto`），无需数据迁移，只需调整解读逻辑与设置页文案（见 §11.3、§11.4）。

## 四、信息架构重组

### 4.1 新导航结构（11 入口 → 5 入口）

```
首页        /dashboard        仪表盘 + 今日焦点
学习        /roadmap          路线图为默认视图，页内 Tab：路线图 | 任务 | 专注 | 日志
职业        /career           页内 Tab：画像 | 技能树 | 简历 | 面试 | 市场   ※ 招花并入
招花        /jobs             职位信息流 + 收藏 + 爬虫状态（保持独立，信息流场景重）
设置        /settings
```

**归并理由**：

- 「今日任务 / 专注 / 日志」本质是"学习"的执行动作，且专注本来就寄生在 /tasks#focus，收敛为「学习」入口内的 Tab，导航从 11 降到 5，符合 Miller 7±2。
- 「我的求职 /applications」并入「招花」页的「我的」Tab（求职就是对职位流的操作记录），「市场分析」留在「职业」Tab（分析服务于职业规划）。这样"看职位去招花、看分析去职业"，职责一刀切清楚。
- 「健康」从一级导航移除，保留浮动组件（现状即浮层，不占导航位）。
- 移动端底部 Tab 与 Web 侧边栏一一对应：**首页 / 学习 / 招花 / 职业 / 我的(设置)**，5 个 Tab 正好是移动端舒适上限。

### 4.2 布局骨架（保持不变的部分）

- Web：左侧 Glass-1 导航栏（宽 232px，可折叠为 64px 纯图标）+ 右侧内容区。
- 导航栏底部保留"当前职业 + 整体进度"迷你卡（现有好习惯，保留）。
- 移动端：底部 Glass-1 Tab 栏 + 顶部页面标题栏。
- 登录页不渲染导航壳（现状逻辑保留）。

**关键决策**：
- "今日焦点卡"是页面唯一主角：下一个未完成任务 + 一键开始专注（跳转 /tasks#focus 并自动带上该任务），把"看"和"做"合并成一步。这是本次改版对用户习惯最大的改进——现状用户要看任务再去任务页点专注，两步变一步。
- 进度环、打卡、专注时长收进右侧"状态列"，数字 count-up 动效保留（现有实现良好）。
- GitHub 热力图、最近日志、健康提醒退到第三层，弱化呈现。
- 技能缺口卡（现有 dashboard-gap-card）保留，色板改为 accent 青。

**数据依赖**：`/api/summary`、`/api/tasks?date=today`、`/api/skills/gaps`、wellbeing API —— **全部现有，零 API 改动**。

#### 5.1.1 快捷开始区：一键学习 / 一键运动（v1.1 新增）

**位置**：问候主视觉区正下方、「今日焦点」上方，两张等宽大按钮卡片并排（移动端上下堆叠）。「当前任务 / 今日焦点」区域**保持不动**，快捷开始是独立新增的一层。

**设计理由**：「今日焦点」解决的是"计划内的事"（下一个任务），快捷开始解决的是"计划外的冲动"——用户此刻就是想学一会儿 / 动一会儿，不需要先建任务。两个入口互补不冲突。

**卡片样式**：
- Glass-2 卡片，高 72px，lg 圆角，左侧 40px 图标 + 主标题 + 一行副标题（默认时长说明）。
- 一键学习：图标 `BookOpen`，主色 primary 靛蓝描边/图标；副标题"25 分钟专注 · 立即开始"。
- 一键运动：图标 `Dumbbell`（或 `Zap`），accent 青描边/图标；副标题"30 分钟计时 · 立即开始"。
- hover：上浮 2px + 阴影加深（沿用 §六 卡片规范）；press：scale(0.97)。

**交互流程**：

```
一键学习                                  一键运动
   │                                         │
   ▼                                         ▼
跳转 /tasks?autofocus=study&minutes=25    跳转 /tasks?autofocus=exercise&minutes=30
   │                                         │
   ▼                                         ▼
tasks 页读取参数 → openTimer(null,null)   同上（运动模式）
   │                                         │
   ▼                                         ▼
FocusTimer 全屏倒计时**自动开始**           FocusTimer 全屏倒计时**自动开始**
（不绑定任务，自由专注）                   （环形描边改 accent 青，标题显示"运动中"）
   │                                         │
   ▼                                         ▼
完成 → 现有专注打卡分享卡片流程            完成 → POST /api/wellbeing/exercise
（POST /api/focus/*，计专注时长）          {type, durationSeconds, source:"FOCUS"}
                                          → Toast"运动完成 +X 分钟"，计入仪表盘"运动"
```

**边界情况（硬性规则）**：

| 场景 | 行为 |
|---|---|
| 已有计时进行中再次点击 | 跳转回进行中的计时界面，**不重启、不打断** |
| 进入后想改时长 | 倒计时开始前 3 秒内可点预设（15/25/45）切换，超时锁定时长；运动默认 30 分钟对齐 `exercise_goals` 默认目标 |
| 提前结束（学习） | 按现有逻辑处理（不足 1 分钟不计入，现有 FocusTimer 行为保留） |
| 提前结束（运动） | 按实际时长记录：`POST /api/wellbeing/exercise {durationSeconds: 实际秒数, source:"FOCUS"}`；不足 1 分钟 Toast 提示"不足 1 分钟，未计入" |
| 运动模式是否计专注时长 | **不计**。运动只写 exercise_logs，不进 focus sessions，避免两个统计口径互相污染 |
| 移动端 | 首页同样位置放两个按钮，点击跳"学习"Tab 的专注页并自动开始，行为与 Web 完全一致 |

**数据依赖（关键结论：零 API 改动）**：
- 学习路径：现有 `openTimer()` + `/api/focus/*`，仅新增 URL 参数解析与 autoStart。
- 运动路径：`/api/wellbeing/exercise` 的 POST 白名单 `SOURCES` **已包含 `"FOCUS"`**，运动完成直接写入即可；仪表盘"运动"统计读 `/api/wellbeing/today`，自动刷新。
- 前端改动点（仅 3 处）：① dashboard 新增快捷开始组件；② tasks 页读取 `autofocus/minutes` searchParams 自动调 `openTimer`；③ FocusTimer 新增 `autoStart` 与 `mode: "focus" | "exercise"` 两个 props，exercise 模式完成时改写运动 API。

## 十一、浅色油画系列视觉改版（v1.2 新增，2026-09-04）

> 本章是视觉方向的调整：**壁纸收敛、风格换肤**。与 §3（玻璃体系）冲突时以本章为准；信息架构（§四）、快捷开始（§5.1.1）、组件/动效规范（§六/§七）不受影响，继续有效。

### 11.1 需求与核心原则

用户需求：进入全屏专注计时时背景图为每日 Bing 壁纸；**其他页面不再以壁纸为背景**，整体改为浅色油画系列 UI。

三条原则：
1. **壁纸属于专注时刻。** Bing 壁纸只出现在全屏倒计时这一个沉浸场景——它是"进入心流"的仪式感开关，而不是全站皮肤。
2. **画布承托内容。** 日常页面用浅色油画风格：暖米白画布底 + 纸感卡片 + 莫兰迪低饱和色，安静、柔和、长时间阅读不疲劳。
3. **换肤不换骨。** 布局、导航、信息架构、组件层级全部不变，只改材质与色板；tokens 集中管理，换肤成本低、可回退。

### 11.2 壁纸策略调整

| 场景 | 现状 | v1.2 改后 |
|---|---|---|
| 全屏专注计时 | 三种背景模式（纯色/上传/图库） | **保留，默认模式改为"每日 Bing 壁纸"**；浮层继续用现有通用 `.glass` 与 `backdrop-blur-md`（代码实态如此，`.glass-3` 并未被引用） |
| 其他所有页面 | daily-background 全站铺壁纸 + 玻璃卡片 | **不再渲染壁纸层**，改用画布底色 + 纸感卡片 |
| Bing 爬虫 | 每日抓取 | **继续运行，零改动**（专注页仍每日用图） |
| 设置页背景设置 | "每日背景图"全站开关 | 改为「**专注页背景**」设置：来源（Bing/自定义/纯色）+ 当前图更换；全站壁纸开关移除 |

### 11.3 油画系列设计 tokens（浅色）

在 `packages/ui/src/index.ts` 新增 `oilPainting` 色板（不动现有 tokens，便于灰度与回退）：

| Token | 值 | 用途 |
|---|---|---|
| `canvas` | `#f6f2ea` | 页面画布底（暖米白） |
| `surface` | `#fffdf7` | 纸感卡片实底 |
| `canvasTexture` | SVG feTurbulence 噪点 data-URI，opacity 0.03 | 极淡画布纹理（无外部资源依赖，可关） |
| `text` | `#3a3630` | 正文（暖灰黑，比纯黑柔和；对 surface 11.8:1） |
| `textMuted` | `#6f6a63` | 次要文字（对 surface 5.27:1，替代原 `rgba(58,54,48,.60)` 仅 3.59:1） |
| `border` | `rgba(90,80,60,0.14)` | 卡片细描边（暖灰；装饰性描边，可低于 3:1） |
| `primary` | `#46617a` | 主色：雾蓝（白字 6.46:1 / 深字 6.35:1，替代 #5f7d9c 的 4.21:1） |
| `accent` | `#a5662e` | 强调：赭橙（文字 4.55:1 / 白字 4.63:1，替代 #c98a4b 的 2.86:1） |
| `success` | `#5f7d59` | 灰绿（文字 4.52:1，替代 #7d9b76 的 3.03:1） |
| `warning` | `#8f6a2a` | 土黄（文字 4.84:1；填充底色可用更浅 #c9a04b 配深色文字） |
| `danger` | `#a0524a` | 砖红（白字 5.53:1，替代 #b6675f 的 4.05:1） |
| `chartSeries` | `["#5f7d9c","#7d9bb8","#a3b8cc","#c98a4b","#8a9a5b"]` | 图表填充序列（非文字，可保留低饱和浅色；文字/图例须走语义 tokens） |

> **可及性校准（WCAG AA）**：上表语义色已统一按「正文/按钮文字 ≥ 4.5:1」重新取值。v1.2 初稿的 `textMuted`、`primary`、`accent`、`success`、`warning`、`danger` 均未达标（实测最低 2.40:1），在保持「暖灰 + 莫兰迪低饱和」的前提下向下限加深即可达标，同时显著改善可读性；`accent` 若要保留更鲜亮的装饰感，可将图表填充、大图标等非文字场景继续使用 `#c98a4b`，但文字/小图标必须用 `#a5662e`。

**纸感卡片（.paper-card）规范**：实底 `surface` + 1px `border` 描边 + 双层柔和阴影（`0 2px 8px rgba(60,50,30,.06)` + `0 12px 32px rgba(60,50,30,.08)`），圆角沿用 lg(16)；hover 仅阴影加深，不上浮（油画风格求"稳"）。**关键改动：日常页面卡片从"透明玻璃"变为"实底纸卡"，文字可读性彻底脱离背景图波动问题（§一 问题 5 由此根治）。**

**玻璃体系的去留**：`.glass` / `.glass-1/2/3` 全部保留，但仅用于 ① 专注计时页浮层 ② 弹窗/Toast 等浮层场景；导航栏从玻璃改为实底 `surface` + 底部 1px 描边。

**主题机制调整**：v1.1 的三档改为——**浅色（油画系列，默认）/ 深色（沿用现有玻璃深色）/ 跟随系统**。"跟随壁纸"档位取消（壁纸不再影响全局）；已迁移到 auto 的老用户落到"跟随系统"，浅色视觉从玻璃变为油画（这是本次换肤的预期变化）。深色档本期不做油画化，保持现状。

**跟随系统的落地方式**：设置页「跟随系统」档位下，用 `window.matchMedia("(prefers-color-scheme: dark)")` 决定是否挂 `html.dark`（替换现状由 daily-background 写 `html.bg-dark` 的隐式逻辑），并监听 `change` 事件实时切换；手动浅色/深色仍然显式开关 `dark`。

**纸卡的深色变体（易遗漏的回归点）**：`.paper-card` 采用实底 `surface`，若只做“类名替换”会让深色模式出现「白底白字」失效。必须同步提供 `html.dark .paper-card` 变体（深色 `surface` / `text` / `textMuted` / `border`），深色档即使不做油画化也要保证替换后的卡片可读、可用。

**`chartSeries` 单一事实源**：油画图表序列应落地在 `packages/ui/src/index.ts` 的 `oilPainting.chartSeries`（与 §9 的「tokens 单一事实源」一致），再由 Web 与移动端引用；同时替换 `market-charts.tsx` 里硬编码的 `G` 数组（现在是旧的 6 色/5 组冷调渐变），而不是只在文档里“提到”。图表填充属非文字，可保留浅色；图例文字、坐标轴刻度仍走语义色并满足对比度。

**`canvasTexture` 的实现与降级**：`canvasTexture` 采用内联 SVG `feTurbulence` 作为 `background-image` data-URI（`url("data:image/svg+xml,...")`）。落地时需确认 Next.js CSP 允许 `img-src/style-src 'self' data:`（如 CSP 收紧则改为生成一张 2px 噪点 PNG 资源）；必须提供关闭开关（CSS 变量 `--canvas-texture-opacity: 0` 或 settings 开关），并受 `prefers-reduced-transparency` 约束降级为纯色。此纹理为可选增强，不作为验收阻断项。

### 11.4 页面影响清单（改动点）

### 11.5 分阶段实施

| 阶段 | 内容 | 验收 |
|---|---|---|
| **A. tokens + 底色** | globals.css 油画 tokens（§11.3 校准值）、`.paper-card`（含深色变体）、body 底色 | 页面底色为画布米白，无壁纸；深色模式下纸卡可读 |
| **B. 卡片迁移** | 各页 `.glass` → `.paper-card` 批量替换 + 逐页走查 | 各页卡片实底纸感，无残留玻璃卡片（专注页/浮层除外） |
| **C. 壁纸作用域收缩** | daily-background 全局移除；`ui-store.backgroundEnabled` 废弃；`focus-bg-store` 默认 `bing`；设置页「专注页背景」+「跟随系统」三档 | 非专注页任何情况下不出现 Bing 壁纸；专注页默认每日 Bing；`auto` 跟随系统实时切换 |
| **D. 打磨回归** | 对比度 audit（§11.3 语义色 ≥4.5:1）、图表色板确认、`ui-store`/`focus-bg-store` 测试回归、全量测试与构建回归 | 全量测试通过，逐页截图走查签字；URL/背景开关等旧偏好不触发异常保留 |

**风险**：B 阶段批量类替换可能有个别页面视觉回归（如依赖玻璃透明度的叠加场景）——逐页截图走查兜底；油画色板为新增 token，回退只需切回旧引用，成本低。

**与 v1.1 的关系**：v1.1 功能（快捷开始/主题三档/图表收敛）已实施待部署；v1.2 在其之上换肤，建议 **v1.1 预览确认后与 v1.2 合并实施、一次部署**，避免两次全站视觉变更。

### 11.6 冲突解决对照表与实施注意清单（v1.2 评审补充）

**冲突解决对照表**（评审时发现历史章节与 §11 存在多处理论冲突，统一以 §11 为准）：

| 冲突点 | v1.1 / 前文表述 | v1.2 终态 |
|---|---|---|
| 壁纸作用域 | §2/§5.4：全站每日 Bing 壁纸 + 玻璃卡片 | 仅全屏专注计时用 Bing 壁纸；其余页面用 `canvas` 画布底 |
| 主题三档 | §3.5/§5.4：浅色 / 深色 / 跟随壁纸（默认） | 浅色（默认）/ 深色 / 跟随系统；`auto` 语义改为系统 `prefers-color-scheme` |
| 全站壁纸开关 | `ui-store.backgroundEnabled` 控制全局 | 废弃；设置页改为「专注页背景」读写 `focus-bg-store` |
| 浅色色板 | §3.1 靛蓝系（primary #4f46e5 等） | 浅色改用 §11.3 油画 tokens；深色沿用 §3.1 深色列 |
| 玻璃层级 | §3.3 三级玻璃 `.glass-1/2/3` | `.glass` 仅留文档提到的专注浮层/弹窗；`.glass-1/2/3` 现状就未被引用，导航改实底 `surface` |
| 图表色板 | `market-charts.tsx` 硬编码 6 色 | 读 `packages/ui` 的 `oilPainting.chartSeries` |
| 专注默认背景 | `galleryId: "sunset"` | `galleryId: "bing"`（`mode` 仍 `"gallery"`） |

**实施注意清单**（避免只改类名导致回归）：

1. **深色纸卡**：`.paper-card` 必须有 `html.dark` 变体，否则深色模式白底白字（已在 §11.3 明确）。
2. **跟随系统**：`auto` 档用 `matchMedia("(prefers-color-scheme: dark)")` + `change` 监听挂 `html.dark`；替换 daily-background 隐式 `bg-dark` 逻辑（§11.3）。
3. **存储迁移**：`ui-store.backgroundEnabled` 移除时可让 zustand persist 忽略遗留字段即可（不强制清 key）；`ui.theme` 枚举不变、无需版本升级，仅更新注释与测试。
4. **专注兜底**：Bing 无图时沿用专注页现有深色渐变兜底，避免“默认 bing”在离线时报空白。
5. **对比度**：节选「§11.3 可及性校准」的 6 项 token 为硬验收项，逐页 audit 时重点抽查 `textMuted`、`primary` 按钮、`accent` 图标。
6. **canvasTexture 可选**：纹理是增强项，受 CSP / reduced-transparency / 开关三重约束，不作为验收阻断（§11.3）。
