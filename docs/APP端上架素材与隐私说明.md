## 2. 应用简介文案

**一句话（≤30 字）**
> 把学习、求职和健康放进一个工作台，每天只推进一步。

**短描述（≤80 字，市场列表用）**
> 苦旅把「学习路线 · 每日任务 · 专注计时 · 求职雷达 · 训练饮食习惯」收进一个工作台：今日完成度一眼看清，专注计时后台不丢秒，数据本机优先、登录后与 Web 端同步。

**长描述（≤500 字）**
> 苦旅是一个面向长期成长的自律工作台。
>
> · 今日：完成度进度弧 + 四域入口（学习 / 职业 / 健康 / 习惯），今日任务只显示最要紧的三条；
> · 学习：学习阶段路线图、费曼日志、领域计量（单词 / 跑量 / 训练量），专注计时支持后台与锁屏继续计时；
> · 职业：招花职位聚合与筛选、就业雷达匹配度、证书有效期提醒、简历资产与 A4 预览；
> · 健康：训练记录与容量统计、热量与三大营养素、习惯打卡与连续天数；
> · 数据：本机离线可用，登录后与 Web 端（learn.yuanabd.cn）双向同步，等价于「手机 + 电脑同一个工作台」。
>
> 没有信息流、没有广告、没有社交压力：打开就是今天要做的事。

**更新说明（v1.3.1，可直接填市场「更新日志」）**
> · 修复专注计时在某些情况下不走秒的问题
> · 底栏改为通栏扁平样式，所有页面滚到底不再被遮挡
> · 子页面返回回到所属模块（不再一律跳回首页）
> · 底部弹层支持键盘避让与滚动，长表单不再被键盘挡住
> · 今日/健康改用完成度进度弧与状态分，学习统计收进独立面板
> · 今日饮食支持手动录入；习惯支持图标选择与可选时间段

## 3. 权限说明（送审必填：逐条给出用途）

> 以下清单由 `aapt2 dump badging learn-workbench-v1.3.1.apk` 实测导出，与安装页展示一致。

| 权限 | 用途 | 说明 |
|---|---|---|
| `INTERNET` | 账号登录、云端同步、职位/市场数据、OTA 检查更新 | 核心功能必需 |
| `ACCESS_NETWORK_STATE` / `ACCESS_WIFI_STATE` | 判断是否联网/是否 Wi-Fi，用于「离线优先」同步策略 | 只读连接状态，不采集网络标识 |
| `VIBRATE` | 打卡/完成任务的轻触反馈 | 可在系统设置关闭，不影响功能 |
| `USE_BIOMETRIC` / `USE_FINGERPRINT` | 由 `expo-secure-store` 引入：把登录令牌放进系统 Keystore（硬件保护） | 不采集任何指纹/生物特征数据 |

**已主动移除**（`app.json` 的 `android.blockedPermissions`，构建脚本会断言）：
`SYSTEM_ALERT_WINDOW`（悬浮窗，本应用不需要）、`CAMERA`、`RECORD_AUDIO`。
v1.3.0 及以前安装页会显示「显示在其他应用上层」，v1.3.1 起不再出现。

**存储权限说明**：仅声明 `READ/WRITE_EXTERNAL_STORAGE` 且带 `android:maxSdkVersion="32"`（Android 12 及以下由 Expo 图片/文件能力引入），
Android 13+ 不申请任何存储权限；应用不读取相册与文件列表。

> 送审填表建议：把上表四行照抄即可；如市场要求填「是否收集个人信息」，按第 4 节口径填写。

## 4. 隐私口径（与 privacy.html 一致）

| 项目 | 说明 |
|---|---|
| 收集的信息 | 账号（用户名 + 密码哈希 / 微信 openid，可选）、用户主动录入的学习/求职/健康记录 |
| 是否上传 | 登录后同步到自建服务器（腾讯云，境内）；未登录时仅存本机（AsyncStorage / Keychain-Keystore） |
| 第三方 SDK | **无**广告、无统计 SDK；仅使用开源库（见 `docs/THIRD_PARTY.md`） |
| 设备信息 | 不采集 IMEI / MAC / 通讯录 / 相册 / 位置 |
| 注销与删除 | App 内「我的 → 账号与安全」提供注销；亦可发邮件申请删除全部数据 |
| 数据出境 | 无（服务器位于中国境内） |

## 6. 送审注意（历史踩坑）

1. **签名不能换**：换 keystore = 备案与微信登记全部失效（看板踩坑点 14/23）。
2. **权限收敛已在构建脚本里断言**：若某次 prebuild 后忘了恢复，脚本会直接失败（`SYSTEM_ALERT_WINDOW` 回到清单即报错）。
3. **启动图配色**已从 `#208AEF` 改为品牌画布 `#FDF8EF`（深色 `#171209`）；改 `app.json` 后必须让脚本重新补 `res/values{,-night}/colors.xml`（`android/` 不进 git）。
4. **R8 / 资源裁剪默认关闭**：包体已达标（约 66MB，目标 ≤70MB）。需要更小包体时用 `-EnableR8`，并且**必须在真机回归通过后**才能设为默认（R8 可能破坏反射，无设备验证不要开）。
5. 每个市场要求不同：华为要「应用版权证书/软件著作权」或备案截图；小米/OPPO/vivo 要隐私政策 URL + 权限说明（本文第 3、4 节可直接粘贴）。
