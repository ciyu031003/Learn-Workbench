# 发布清单（每次发版照做）

> 起因：v1.32.0–v1.33.0 四个**已上线**版本的源码，在本地工作区躺了一周没进 git（HEAD 停在 v1.31.0/50）。
> 这份清单把"发完版就结束"改成"发完版必须落地"，配套闸门：`pnpm check:release`（或 `pnpm test:scripts` 里的同名检查）。

## 0. 发版前

- [ ] `pnpm check:release` 通过（版本号三处一致 / 最新 tag 之后没有"版本大于 tag 但工作区脏"）
- [ ] `pnpm -F mobile typecheck && pnpm -F mobile test && pnpm -F mobile lint`
- [ ] `pnpm -F web typecheck && pnpm -F web test`
- [ ] `node scripts/check-font-scale.mjs`（字阶棘轮；如确实收紧，跑 `--update` 并提交基线）

## 1. 出包与部署

- [ ] 出包：`scripts/build-android-release.ps1 -VersionName x.y.z -VersionCode N`（脚本会同步 build.gradle / app.json / package.json / ota.ts）
- [ ] 核验签名：apksigner 签名 MD5 必须是 `3057105285981cc18597a95c1370c147`（与备案一致，不一致禁止发布）
- [ ] 记录 APK 体积 / MD5 / SHA256
- [ ] Web 有改动时：打 tar（**排除** `.backup`/`.pnpm-store`/`prototype`/`playwright-report`/`android`/`node_modules`/`.local`/`.env*`/`job-hosts`）→ scp → 服务器解包 → `docker compose up -d --build`
- [ ] APK → `/data/learn-workbench/releases/`（服务器 md5 必须与本地一致）
- [ ] OTA 清单：`node scripts/build-ota-manifest.mjs --apk … --version … --code … --notes … --out <门户>/demo/mobile-update.json`
- [ ] 门户：`demo/download.html` 5 处版本 + 二维码 `npx qrcode -o demo/img/learn-download-qr.png -w 640 -m 2 "<新 APK URL>"` + 改 `?v=` 缓存参数

## 2. 线上核验（缺一项不算发布完成）

- [ ] `curl -I https://learn.yuanabd.cn/download/learn-workbench-v<ver>.apk` → 200 + Content-Length 与本地一致
- [ ] `curl -s "https://learn.yuanabd.cn/mobile-update.json?t=$RANDOM"` → versionName/versionCode/sha256/sizeBytes 正确
- [ ] `download.html` 线上含 5 处新版本、**旧版本残留 0**、二维码 `?v=` 已更新
- [ ] 二维码 jsQR 解码指向新 APK（`npx qrcode` 生成的图是静态图，**必须**解码核验）
- [ ] 有 Web 改动时：关键接口自测（未登录 401、新路由 200/401 符合预期）

## 3. 发版后必须落地（本次事故就是漏了这步）

- [ ] `git add -A && git commit`（版本号 bump 与代码在同一条线）
- [ ] `git tag -a v<x.y.z> -m "…"` 并 `git push origin main --tags`
- [ ] 门户仓库（`F:\CodeFiles\YuanAbd-Web`）：`git fetch` → 有分叉先 merge/rebase → `git push`
- [ ] 回看板：追加本版发布记录（APK 哈希 + 线上核验结果 + 回滚方式）
- [ ] `pnpm check:release` 再跑一次，确认"发布版已进 git、远端不落后"

## 4. 回滚

- 门户清单换回上一版 `mobile-update.json` 即停止推送（APK 文件保留在桶里，可直接回滚）
- Web 回滚：服务器上 `git` 不在，需重新 scp 上一版 tar 再 `docker compose up -d --build`
