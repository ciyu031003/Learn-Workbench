## 1. 今日焦点卡组：从「纯淡化」改为「堆叠 + 3D 翻转」

**旧实现的问题**（v2 阶段曾为了修「上滑弹跳」而退化为纯淡化）：只有 opacity 变化，没有堆叠层次，切换很平淡。

**新交互（按真机描述逐条对齐）**

| 需求 | 实现 |
| --- | --- |
| 第一张占主体，后面第二张在后面、缩小、压暗但看得见 | 三层空间堆叠：front（scale 1 / z30）、nextTop（scale 0.94、上移 11pt 露沿、opacity 0.55 / z20）、rest（scale 0.88、上移 22pt、opacity 0.24 / z10） |
| 下滑：第一张向下消失，第二张自然顶上 | front 绕 X 轴 0°→**68°（锐角）**、下移 176pt、scale→0.86、opacity→0；nextTop 同步由背面姿态插值到主体 |
| 上滑：上一张从下方翻回来 | front 反向旋转 -68°、上移 176pt 淡出；prevBottom 由下方姿态（+11pt / +18°）插值回主体 |
| 不要弹跳 | 全部 `withTiming` + `Easing.out(cubic)`（330ms），**不使用弹簧**；手势未过阈值时 200ms 平滑回落 |
| 有手感 | 拖动过程中按位移映射成最多 45% 的过渡进度（卡片随手同向轻微翻转/位移），松手再决定完成或回位 |
| 固定在拟态容器里 | 外层「拟态托盘」：`surfaceMuted` 底 + 柔和外阴影 + 顶部 1px 高光 + 32 圆角，卡片只在托盘内切换 |

**实现要点**
- 卡序是一个环形队列：`order[0]` 是主体；下滑 `[...prev.slice(1), prev[0]]`；上滑 `[prev[prev.length-1], ...prev.slice(0,-1)]`；
- 两个共享值驱动全部动画：`p`（过渡进度 0..1）、`dir`（>0 下滑 / <0 上滑）；每张卡的 `role` 是渲染期常量，worklet 只读共享值 —— 满足 v6 踩坑 71/78/79 的硬约束（引用量声明在 worklet 之前、worklet 内不调外部普通函数）；
- `backfaceVisibility: hidden` + `perspective: 900` 保证翻转不露背面镜像；
- 保留页码圆点做可发现性线索。
