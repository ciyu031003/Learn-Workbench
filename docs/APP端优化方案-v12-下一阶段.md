## 2. 执行清单（一个版本内做完）

### P0 · 修「烂」

**P0-1 首页统计与习惯入口消失**
- 现状：`components/daily-os-summary.tsx` 里 `if (!data) return null` → 接口失败整块消失。
- 改法：三态化（骨架 / 错误+重试 / 正常）；回到前台自动重拉 + 下拉刷新；失败写诊断日志。
- 验收：断网或 500 时首页仍显示骨架与重试，不再"整块消失"。

**P0-2 饮水按钮无反应 + P0-3 健康页不显示饮食**
- 改法：`quickWater()` 乐观更新 + 明确失败提示（不再静默 catch）；统一 `/api/daily` 与 `/api/nutrition` 的当天口径；写入后定点回读 hydration/nutrition 摘要。
- 验收：健康页点 +200 立即变化并落库；饮食录入后健康首页立即显示。

**P0-4 闪光卡返回健康**
- 改法：档案/闪光卡返回统一 `router.replace("/wellness")`（或按来源参数），系统返回键行为一致。

**P0-5 状态栏黑屏**
- 已确认：浅色/深色都出现，多数是黑带、偶尔整块黑。截图证据 → 顶部状态栏区域没有铺到主题底色。
- 改法：① 壳层在状态栏高度区域先铺 `colors.canvas`（`ThemedShell` 根 View 加背景 + 顶部安全区填充）；② 统一 `expo-status-bar` 的 translucency 与 `styles.xml` 的 `statusBarColor`；③ 排查各页 `root: { backgroundColor: "transparent" }` 在边到边渲染下露出窗口黑底的情况，统一改为继承壳层底色。
- 验收：浅色/深色各截图一张，状态栏区域与页面顶部同色，无黑带/整块黑。

**P0-6 7 天柱状图可点**
- 改法：`weekCell` 改 `Pressable`（整列可点，含空白），选中态动画。

**P0-7 删除今日焦点堆叠**
- 改法：移除 `<TodayStack />`、`stackGestureActive` 及组件文件；首页顺序变为「一键开始 → 我的一天（统计） → 运动·健康 → 今日任务 → 更多」。

**P0-8 计时后台常驻 + 精美通知**
- 改法：
  1. Android **前台服务**（Kotlin，直接改 `android/` 工程）+ 常驻通知；
  2. 通知用**自定义 RemoteViews**：左 = 圆环（倒计时=剩余进度环 / 正向计时=已用进度环，随秒刷新位图）、右 = 当前任务或习惯名 + 时间文本；配色跟随 App 主题；
  3. 会话状态持久化（`startedAtMs` 落盘），进程被杀后回来仍算对时长并提示"计时中断"；
  4. 构建脚本继续做签名 MD5 校验（不动签名流程）。
- 验收：锁屏/切后台 30 分钟以上不被杀、通知环在走、任务名正确；回来时长一致。

**P0-9 档案图片布局与点击弹窗**（§1）
- 改法：配图规则 `racket|shoes|string`；布局 = 头像横屏 + 球拍横屏 + （球鞋｜拍线）两列；点击任一图片位 → 弹层选择「本地相册 / 图库 / 删除」。

**P0-10 圆环与数字动效**
- 改法：切「今天/昨天」时圆环**平滑过渡**（不重挂载）、数字滚动、进度色随达成度；周/月同。

### P1 · 体验与设计

**P1-1 悬空玻璃 TabBar（不降级）**
- 形态照参考图：悬空圆角胶囊、离底间距、选中项胶囊高亮、图标 + 小字；浅色"亮玻璃"、深色"暗玻璃"；`TAB_BAR_HEIGHT` 与各页底部留白同步。

**P1-2 习惯重做（油画质感）+ 编辑/删除 + 同步每日任务（两者都要）**
- 长按 → 底部小窗（编辑 / 删除）；点击 → 编辑页（名称、频率、时间、颜色、图标、备注）。
- 卡片：多层柔和渐变 + 纹理/噪点 + 手绘感边框的**油画质感**，完成态用优雅的"盖章"表达。
- 同步：新建习惯**自动生成同名每日任务**；同时首页「今日任务」**合并展示**习惯排期（两者都要）。

**P1-3 全站 UI 精修（提质，不只是推广）**
- 把健康/饮食已验证的语言（语义色、hero、留白、玻璃层级、动效节奏）沉淀成共享组件与 token，然后逐页重做：**首页 → 学习 → 我的 → 职业 → 招花 → 设置**。
- 每页给出前后对比，跑全量测试，避免回归。

### P2 · 新能力

**P2-1 面试题库（COS + 爬虫 + 参考答案）**
- 链路：`scripts/crawl_interview.mjs`（只抓公开题库/面经，保留来源与许可）→ 规范化（题目/岗位/难度/标签/参考答案/来源）→ COS `interview/` → 同步 PG → APP 读接口。
- 客户端：列表筛选、刷题、**自填答案 ↔ 参考答案并排对照**、收藏、错题本、我的题目；组件参考开源题库/Anki/LeetCode 设计出 3 套草图。
- 合规：来源标注 + 一键下架（`is_listed` 同款）。

**P2-2 简历存 COS**
- `POST /api/uploads` 扩展 `pdf/doc/docx`（≤5MB、类型与内容校验）→ COS `resume/`；简历表加 `file_path`；上传/替换/预览（PDF 用系统预览或 WebView）；分享用**签名 URL**（私有桶）。

## 3. 风险与依赖

- **前台服务 + 自定义通知**：需要写 Kotlin 与 RemoteViews 布局、加权限；不做 prebuild（沿用直接改 `android/` + 签名校验的既有约定）。低端机通知栏样式差异需要真机复看。
- **状态栏**：三条候选根因需要逐个验证（改完必须浅色/深色真机截图确认）。
- **题库版权**：只收公开可抓取内容、保留来源、可下架；站点反爬与来源失效需兜底（本地留最近一次成功快照）。
- **COS 私有化**：简历/PDF 走私有桶签名 URL，需要新增服务端签名与有效期策略（图片仍是公开直链）。
- **全站 UI 精修**：面最大、最易回归 —— 每页替换后跑 web 1132 / mobile 318 全量测试 + 真机截图。
