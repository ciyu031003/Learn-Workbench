## 2. 批次划分

### P0 · 修「烂」（先让现有功能对起来，出一版 v1.20.0）

**P0-1 首页统计与习惯入口消失（最优先，属数据丢失感最强的一类）**
- 现状：`daily-os-summary` 在 `!data` 时 `return null`。
- 改法：
  1. 三态化：`loading → 骨架屏`、`error → 卡片内提示 + 重试按钮`、`ok → 正常渲染`；**永不静默消失**；
  2. `/api/daily` 失败时把错误上报到诊断页（已有 `lib/diagnostics`）便于你复现时给我日志；
  3. 首页加「下拉刷新」与回到前台自动重拉（大部分统计消失是回到前台后没重拉导致）。
- 验收：断网/接口 500 时首页仍显示统计骨架与「重试」，不再出现「整块消失」；恢复网络后下拉即回。

**P0-2 + P0-3 健康页饮水按钮无反应 / 健康首页不显示饮食**
- 两者都是「写进去了但健康页读不到」的取数问题，合并处理：
  1. `quickWater()` 改成**乐观更新 + 明确失败提示**（成功先本地 +ml 并立即刷新环形；失败弹 Toast 而不是静默 catch）；
  2. 对齐 `/api/daily` 与 `/api/nutrition` 的当天口径（时区/日期参数），健康页饮食块改为读同一聚合；
  3. 写入后做一次**针对性回读**（只拉 hydration/nutrition 摘要）而不是整页 load，减少"看着没变"的窗口。
- 验收：健康页点 +200 立刻看到数字与环形变化，杀掉重进仍一致；饮食录入后健康首页立即显示。

**P0-4 闪光卡返回逻辑**
- 改法：档案页/闪光卡统一「返回健康」语义（`router.replace("/wellness")`），或在导航时带上来源参数按来源返回；同时把闪光卡弹层的关闭按钮与系统返回键行为对齐。
- 验收：从今日、从健康、从分享链接三处进档案，点返回都回到「健康」；安卓系统返回键行为一致。

**P0-5 状态栏黑屏（需你先给一张出问题的截图/机型信息）**
- 三条候选根因：① 深色档 `app_bar_color=#171209` 与页面底色不完全一致造成"黑带"；② 边到边（edge-to-edge）渲染时状态栏区域由窗口背景兜底；③ 启动闪屏 → 首帧之间的底色跳变。
- 改法（按取证结果择一或全做）：统一 `StatusBar` 的 translucent/背景色策略、让壳层在状态栏高度区域**先铺主题底色**、必要时给 `styles.xml` 的 `statusBarColor` 与 App 主题联动。
- 验收：浅色/深色各一张截图，状态栏区域与页面顶部颜色一致，无黑带。

**P0-6 7 天柱状图可点**
- 改法：`weekCell` 换成 `Pressable`（点击切到该天）+ 命中区域放大到整列（含空白），当天高亮 + 选中动画。
- 验收：点任意一天都能切天；点空白列也能命中。

**P0-7 删除「今日焦点」堆叠**
- 改法：首页移除 `<TodayStack />` 与其手势联动（`stackGestureActive`）、清理不再使用的组件/依赖（`components/today-stack.tsx` 及相关 store 字段按需保留或一并删）。
- 验收：首页首屏为「一键开始 → 我的一天（统计） → 运动健康 → 今日任务」，无堆叠卡。
- ⚠️ 见 §3 问题 2：整块删除 vs 保留精简入口。

**P0-8 计时常驻（前台服务）**
- 改法：
  1. 计时开始 → 启动 **Android 前台服务 + 常驻通知**（"学习中 · 已 25:13"），计时结束/暂停即销毁；
  2. 同时开启 `expo-keep-awake`（可选，仅在学习全屏时保持亮屏）；
  3. 会话状态持久化（`startedAtMs` 落 AsyncStorage），即使进程真的被杀，回来也能算对时长并提示「计时中断」；
  4. 需要动 `android/` 原生工程（新增 ForegroundService 与权限），沿用现有「不跑 prebuild、直接改 android 工程」的约定，并在构建脚本里保持签名校验。
- 验收：锁屏/切后台 30 分钟以上，通知常驻、倒计时不丢；返回 App 时长正确。

### P1 · 体验精修（v1.21.0）

**P1-1 悬空玻璃 TabBar（参考你给的两张图）**
- 形态：底部**悬空圆角胶囊**（左右留边、离底有间距、内容在其后滚动穿透），选中项有**胶囊高亮底**，未选中为描边图标 + 小字；浅色/深色各一套（深色偏"暗玻璃"）。
- 实现：复用 `GlassSurface` + `glassSupported()`（低端机降级为半透明纯色），点击保留 `PressableScale` 触感；`TAB_BAR_HEIGHT` 与新形态同步（首页/各页 `paddingBottom` 自动跟随）。
- 验收：5 个 tab 全部可达；透明度/描边在浅色与深色下都清晰；滚动内容不遮挡最后一个卡片。

**P1-2 习惯：编辑 / 删除 / 精美卡片 / 同步每日任务**
- 长按卡片 → 底部小窗（取消 / 编辑 / 删除）；点击 → 进编辑（名称、频率、时间、颜色、图标、备注）。
- 卡片视觉：**油画质感**（多层柔和渐变 + 纹理/噪点感 + 手绘边框），色板与「今日饮食」的语义色统一；完成态用"盖章/描边填充"等优雅表达。
- **同步每日任务**：见 §3 问题 4（自动建任务 / 首页合并展示 / 两者都要）。
- 验收：新建 → 可编辑 → 可删除 → 首页与每日任务都能看到今天的习惯排期。

**P1-3 饮食/健康 UI 语言推广（精修）**
- 把「今日饮食」已验证的语言（语义色卡组、大数字 hero、低权重胶囊、留白节奏）抽成共享组件/样式（`packages/ui` tokens + `components/`），按页面逐个替换：**首页 → 学习 → 我的 → 职业 → 招花**（顺序待你确认，见 §3 问题 9）。
- 验收：每页替换后视觉一致、无回归（截图对比），并在看板留对比图与说明。

**P1-4 圆环/数字动效**
- 饮食页日视图切「今天/昨天」时：圆环**从上一值平滑过渡**（不要 key 重挂载）、数字**滚动跳数**、进度条色随达成度变化；周/月切换同理。
- 验收：切天/切周月都有 300–500ms 动效，不闪烁、不卡顿。

**P1-5 装备图片点击弹窗（本地 / 图库二选一）**
- 点主力装备图/证件照 → 弹层「拍照/相册」「图库选择」「删除图片」；图库分支直接进现有 `EquipmentPicker`，选中后回填型号 + 图片。
- 同时明确**拍线是否纳入配图**（§3 问题 1），并让档案页按钮排序与配图规则一致（球拍 → 球鞋 → 羽毛球 → 拍线）。

## 4. 风险与依赖

- **前台服务**（P0-8）需要动原生工程与权限声明：不改签名流程，但要在构建脚本后继续做**签名 MD5 校验**（现有脚本已内置）；首次上线后要请你真机确认"通知栏常驻 + 不被杀"。

- **题库**（P2-1）最大风险是**版权与可用性**：站点反爬、来源失效；方案里内建"来源可下架 + 只存题目与参考答案 + 不搬原文资源"的兜底。
- **COS 权限**：简历/PDF 建议走**私有桶 + 签名 URL**（现在是图片直链公开），需要新增服务端签名逻辑与有效期策略。
- **UI 语言推广**（P1-3）是"面"上改动，容易引入回归：每页替换都跑 typecheck + 既有单测（当前 web 1132 / mobile 318）+ 真机截图确认。
