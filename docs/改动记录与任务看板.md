## 三、踩坑点（新会话必读）

1. **Windows 仓库大量 CRLF**：apps/web、apps/mobile 部分文件是 CRLF。node 脚本做多行字符串替换时锚点必须含 `\r`（或逐行 split 处理）；锚点匹配失败先查行尾。git 的 LF→CRLF warning 无害。
2. **服务器部署链路**：本地无 rsync → `tar czf - --exclude=... . | ssh tar xzf - -C /home/ubuntu/learn-workbench`，**必须排除** `config/job-hosts`（服务器独有 storageState.json）与 `.env*`，**禁止 --delete**；然后 ssh 跑 `docker compose up -d --build`（deploy-docker.sh 在该服务器因 dash 不支持 pipefail 会挂，直接用 compose）。完整排除清单看 git log 里 6b9bf06 的部署命令。
3. **服务器磁盘**：docker 构建缓存是大头（一次 build 约 6GB 层），连续两次 up --build 就可能打满 60G 盘（报 `no space left on device` 且 compose ps 不变）。急救：杀构建 → `docker builder prune -a -f` → `docker image prune -f` → 重试。已装周日 05:00 cron。注意 travel-notes 的周日 04:30 脚本是全局 prune（docker 层面不分项目）。
4. **数据库迁移只追加不改**：新迁移文件按序号命名放 `db/migrations/`，init 容器幂等执行；**新表必须同步登记 `db/schema.sql`**（`pnpm test:scripts` 的 verify-migrations 会警告未登记表）。种子数据要 `ON CONFLICT DO NOTHING/UPDATE` 保证幂等。
5. **每个 API 路由必须带同目录 `route.test.ts`**（项目铁律）。mock 模式参考既有测试：`vi.mock("@/lib/db")` + `queryMock.mockResolvedValueOnce({rows:...} as never)`。断言多参 SQL 时注意参数是数组整体（`toHaveBeenCalledWith(sql, [a, b])` 而不是逐个）。
6. **next dev 有项目级锁**（`.next/dev`）：僵尸进程会占 3001 端口且不响应 HTTP（curl 超时而非拒绝），还挡住新 dev 启动。本地视觉验收用 `pnpm exec next dev --turbopack -p 3100`；遇到锁先杀占用进程。dev 首次请求触发 Turbopack 编译，curl 超时要给足 120s+。
7. **本地 PostgreSQL**（`scripts/start_pg.ps1`，user=postgres 无密码，db=Learn-Workbench）：Windows 下 pg 可能坏成子进程 `error 487` 无法 spawn——`pg_ctl stop -m fast` 再 `start`；`-o` 里**不能带 `-w`**（那是 pg_ctl 的参数）。
8. **IconPark 图标名陷阱**（生成后必须蒙太奇目检）：`RunLeft`=运行脚本(卡片箭头)不是跑步、`PlayCycle/Cycle`=循环箭头、`Compression`=压缩文件、`Weight`=体重秤、`Stretching`=展开箭头。正确指派：跑步=Sport、拉伸=StretchingOne、俯卧撑=Fitness、平板支撑=Stopwatch、瑜伽=Lotus、八段锦=Kungfu、爬楼梯=Ladder。IconPark 没有自行车/飞盘/太极/仰卧起坐专图（骑行用 lucide Bike 兜底）。本地素材管线在 `.local/iconpark/`（@icon-park/svg 包，fill 数组按路径顺序着色）。
9. **腾讯云 App 备案"公钥"** 填的是签名证书 **RSA 模数的十进制数字串**（不是 SPKI 十六进制！JDK17 keytool 默认不显示 MD5，用 `keytool -exportcert` + `openssl x509 -noout -modulus` + BigInt 转十进制）；MD5 是 32 位小写去冒号。
10. **微信/邮箱功能 env 门控**：未配置 `WECHAT_WEB_APPID/SECRET`、`EMAIL_API_KEY` 时，接口返回 503、前端入口自动隐藏——改相关代码时保持这个约定，别把入口做成硬编码常显。
11. **autofocus 链路**：`/tasks?autofocus=exercise&minutes=N&label=篮球&stype=BALL` → `lib/autofocus.ts`（label 截断 50 字、stype 枚举校验）→ tasks 页 timerAuto → FocusTimer（exerciseLabel/exerciseType props，ref 同步）→ 结算写 exercise_logs。改动参数要同步 `lib/autofocus.test.ts`。
12. **移动端样式已全面主题化**（useTheme + makeStyles(colors) 模式，19 屏）：新组件必须走 `const makeStyles = (colors: ThemeColors) => StyleSheet.create({...})` + `useTheme()`；不要再写模块级静态 StyleSheet 或硬编码 hex。专注全屏（focus-timer）保持暗色沉浸、不随主题。
13. **移动端测试 mock**：store 测试需 `vi.mock("expo-secure-store")` 和 `vi.mock("@react-native-async-storage/async-storage")`（secure-token 引入后新增）。
14. **keystore 是 App 身份**：`apps/mobile/android/keystore/release.keystore` + `keystore.properties`（含密码，勿提交泄漏）。换签名 = 备案/微信登记全部失效。
15. **proxy.ts 只守页面路由**（PROTECTED 列表），API 鉴权在各 route 内自行做（currentUserId）；新增守卫页面记得加列表。
16. **视觉验收流程**：截图存 `.local/accept/`，用 judge 子代理评审（给足场景权重与判定标准）；IP 直连 `https://106.55.2.197` 证书必报错，一律用域名。
17. **微信内测/演示数据**：本地 dev 测试账号 glowtest（本地库）；线上是用户真实数据，**不要在线上做写操作**（注销接口等用本地验证）。
18. **门户仓库是独立 git**（F:\CodeFiles\YuanAbd-Web，deploy 到 **`/data/learn-workbench/landing`**，2026-09-06 起不再是 /var/www/learn-landing）：改 learn.html/download.html 后 `scp` 到 /tmp 再 `sudo cp` 进桶目录，favicon 引用 `./img/app-icon.png`。上传新 APK 同理 → **`/data/learn-workbench/releases/`**。
19. **COS 桶（/data，cosfs FUSE）特性**：`cp -a` 会报 preserving permissions 错（桶不支持 chown/chmod），用普通 `cp -r`；桶上目录可能被其他进程以 www-data 属主预创建（写不进先 `sudo chown -R ubuntu:ubuntu`）；大文件上传会先占本地缓存盘（cosfs `-oensure_diskfree=10240`）；**禁止**把 docker 内部/数据库/node_modules 放桶上（随机小 IO + 锁不可用）；cosfs 支持 HTTP Range（APK 断点续传可用）。
20. **存储迁移回滚兜底**：旧副本 `/var/www/learn-landing` 与 `/var/www/learn-workbench-releases`（约 312MB）保留未删；nginx 备份 `/etc/nginx/sites-available/learn-workbench.bak-20260906`。稳定一周后可清理。
21. **GitHub push 走 HTTPS**（2026-09-06）：本网络 22/443 端口 SSH 到 github.com 都被重置；`git push https://github.com/ciyu031003/Learn-Workbench.git main`（credential manager 已存凭据），Learn-Workbench 已把 push URL 固定为 HTTPS。门户仓库 YuanAbd-Web 的 SSH 有时能通，不通同样换 HTTPS。
22. **本地 PG `error 487`（共享内存映射冲突）重启无效时**：在 `.pgdata/postgresql.conf` 追加 `shared_buffers = 32MB`、`max_connections = 30` 缩小映射再启动（PG18 Windows **没有** `dynamic_shared_memory_type=none` 可选值，加了起不来）。本地库超管是 **postgres** 不是 lwb；应用 db.ts 默认连 postgres。本地视觉验收测试账号 `visual / Visual-2026-Accept`（display_name=visual）。
23. **expo prebuild 会整个重建 `apps/mobile/android/`（android/ 不进 git）**：先把 `android/keystore/` + `android/keystore.properties` 备份（现备在 `.local/keystore-backup/`）再跑，跑完恢复。**版本号与签名的唯一事实源是 `android/app/build.gradle`**——app.json 的 version/versionCode 不会注入（manifest 曾一直是 1.0.0(1)，v1.1.2 起改直接写 build.gradle）；**prebuild 还会把 release 签名重置回 debug**（CN=Android Debug），打出的包装不上正式包！构建前必须确认 build.gradle 有：① defaultConfig `versionCode 4 / versionName "1.1.2"`；② keystore.properties 加载 + signingConfigs.release；③ release buildType `signingConfig keystorePropertiesFile.exists() ? signingConfigs.release : signingConfigs.debug`。打完用 `apksigner verify --print-certs` 校验 MD5=3057105285981cc18597a95c1370c147（与备案一致）。打包：`cd android && ./gradlew assembleRelease -PreactNativeArchitectures=armeabi-v7a,arm64-v8a`（全 ABI 会打出 114MB 的四 ABI 包，正式包只打 arm 双 ABI ≈65MB，约 4-35 分钟视增量）。产物 `android/app/build/outputs/apk/release/app-release.apk`。
24. **Ionicons 字形缺口**：glyphmap 里没有 `volleyball`/`tasks`（用了不显示）。volleyball 用 `baseball` 兜底（sport-view.ts）；iOS 端 sport 图标走 SPORT_SF 的 figure.*（SF Symbols，需 iOS 16+，Android 不受影响）。
25. **门户新增"数据活刷新"标记**：learn.html 手绘稿用 `data-mock-live="<stats 字段>"`（配 `data-suffix` 保单位）与 `data-mock-date`；改 initLiveStats 时别动这段（首文本节点替换，保住 `<i>` 单位）。
26. **XFF 语义（clientIp）**：nginx `$proxy_add_x_forwarded_for` 是追加式——`X-Forwarded-For` 的**首段是客户端可伪造的**，`lib/auth.ts` 的 clientIp 因此只取**末段**；写新限流/审计代码时别再改回首段。
27. **会话 token 双写过渡期**：迁移 033 后代码写入 token+token_hash 两列、读取只走 `token_hash`；`lib/session.ts` 的 destroySession 同时删两列。过渡期（30 天 TTL 过后）在服务器执行迁移文件末尾的「收敛 DDL」删明文列——**不要在过渡期内直接 DROP token 列**（回滚到旧镜像会挂）。
28. **每日爬虫管线的幂等依赖**：cron 的 crawl 幂等守卫查 `job_crawler_runs.status='success' AND started_at >= CURRENT_DATE`——爬虫脚本若改了状态字符串（success/partial/failed），守卫与看板要同步；`partial` 算"没完全成功"，12:30 补跑会重试，属预期行为。
29. **聚合接口的 26h TTL**：`analyzeMarket`/`getPublicStats` 的缓存 TTL 是 26h（不是"每天 0 点过期"），为的是覆盖「今日 05:40 → 明日 05:40」聚合间隔+漂移；改调度时间后要同步调 `CACHE_TTL_MS`/`STATS_TTL_MS`。
30. **换 APK 版本必须重新生成预渲染二维码**（门户仓库 2026-09-06 踩过）：download.html 的码是 img/learn-download-qr.png 静态图，不是 JS 动态画——只改 HTML 链接会导致扫码仍是老版本/死链（旧码编的还是 v1.0.0 地址）。流程：npx qrcode -o img/learn-download-qr.png -w 640 -m 2 "<新 APK URL>" → bump HTML 里 ?v= 缓存参数 → 同步改 hero 标题/dl-row__ver 版本文案 → 部署后用 jsqr 解码线上 PNG 校验。
31. **市场薪资单位是 K，数据库原始值是元**：`/api/market/intelligence` 的查询参数与返回值都按 K 处理，底层 SQL 会 `*100` 或 `/100` 转换。改 salary 过滤/展示时不要直接拿数据库 `salary_min/salary_max` 当 K。
32. **市场字段回填只挂在 aggregate**：12:30 crawl 成功后不会自动回填新职位，未处理前，新抓职位当天可能没有 `function_key/industry_sector/salary_band`。不要误认为「crawl 完就一定有市场字段」。
33. **market_saved_views / market_dimension_snapshots 尚未接线**：034 已建表，但当前没有对应 API/UI/cron writer。不要在实现前删除或改表唯一键，否则保存视图与历史趋势方案要保持兼容。
34. **匿名 API 不要直接调 `currentUserId()`**：`currentSessionToken()` 为空时应直接返回 `loggedIn:false`/401；直接调 `currentUserId()` 在生产 Next/Turbopack 路径可能触发空 token 进入 `hashToken(null)`。新增市场/决策/保存视图接口已改为先取 token。
