# 2.6.6 UI 优化改动记录

本轮按《UI-UX审计与优化方案-2.6.5》的 P0 → P1 → P2 顺序实施，全部提交在 `main` 分支。

## P0（阻断项）

- **Web 移动底栏**：改为「今日 / 学习 / 职业 / 健康 / 我的」五入口；招花从一级 Tab 移回职业页入口，`/wellbeing` 独立高亮。
- **Web 专注层**：全屏计时改为 Portal 到 `body`，补 `role=dialog`、`aria-modal`、Escape 关闭、Tab 焦点圈、关闭后焦点恢复与 body 滚动锁。
- **Web 开始计时**：入口增加「学习专注 / 运动记录」分段；运动可选项目与 15/30/45/60 分钟，记录走既有运动计时链路。
- **Web 横屏壳层**：横屏且高度 ≤500px 时隐藏桌面顶栏、启用移动底栏；专注开始页横屏两栏。
- **Web 职业页**：统计优先；招花 CTA 置顶；移除 P0/P2/P3、MVP、表名等内部术语；未知数据用 `--`；加载失败可重试。
- **睡眠可信度**：评分卡首层显示「设备分期 / 按时长估算 / 手动记录 / 数据不足」；估算文案改为「参考」；新增评分构成展开与近 7 晚均分对比；分期每行标注「实测 / 估算」；估算原因与去授权/重读入口上移到评分卡；小米同步改为 3 步说明。
- **睡眠评分拆解**：`sleepScoreBreakdown` 与总分共用权重，缺项重分配权重；新增单测覆盖。
- **Web 健康页**：新增睡眠能力说明卡；Web 暂不读取手机 Health Connect 数据，明确指向 App，避免把空白误读成「没有记录」。

## P1（体验与可读性）

- 今日页：320 紧凑屏压缩实景带与专注卡；空态隐藏 7 根 0 柱和三组零值；「本周学习」改名「本周专注」。
- 我的页：匿名用户首屏可见「登录 / 注册」胶囊，登录用户可见「编辑资料」；设置组上移到统计之后；空热力图折叠为一行；证书空态压缩为一行。
- 健康页：空数据先显示「今天先记一笔」四宫格（饮水 / 一餐 / 体重 / 睡眠）；三环与趋势在首次记录后出现；趋势改名「本周饮食热量」；错误条与空态不再同时出现。
- 学习页：页头副文案缩短，避免「专注」被拆行；移除重复空态与重复完成度；eyebrow 改中文。
- 专注控制坞：9.5/10.5px 字号提升到 11/12px，白色透明度提高；沉浸层字号登记为 fontscale 例外，`lint:fontscale` 恢复通过。
- 元信息对比度：新增 `textMeta`（白卡 5.10:1、画布 4.61:1），睡眠/健康/职业/今日/设置的信息文本从 `textFaint` 迁移。
- 组件几何：五个 Tab 横向 padding 统一 18；页面卡圆角归一。
- Web：成长页移除 3D 球与流动光斑，改单色进度环；底栏改为 64 高悬浮胶囊并适配横屏/安全区；设置页账号与同步置顶，快捷入口去重为两列工具入口；课程库移动端压缩卡片、筛选吸顶、匿名登录提示只出现一次。

## P2（一致性收口）

- 睡眠二级页移除「睡眠 + 睡眠详情」双标题，只保留顶栏标题与一行说明。
- 职业空态压缩为一行设置入口。
- 中文 display 标题字距归零；数字字距保留。
- 睡眠时长统一中文单位（`7 小时 30 分` / `8 小时` / `0 分钟`）。
- 健康 / 职业 eyebrow 改中文；数字与单位补空格。
- Web 内容最大宽度收到 1120px；底栏链接补 `aria-current` 与键盘焦点环。
