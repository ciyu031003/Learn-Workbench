# 运动闪光卡（v10）：把 sports-cards 的全息卡牌内嵌进「运动档案」

> 来源工程：`E:\Codex_output_files\sports-cards`（7 个球类项目的全息卡牌 demo）。
> 本文记录「只取闪光卡片部分」的取舍、数据模型、卡面映射与双端实现。

## 1. 只拿闪光卡：源工程里什么要、什么不要

| 源文件 | 处理 |
| --- | --- |
| `<sport>/web/app.js` | **要**：three.js 场景 + 镭射着色器（front/edge/back 三段）+ 拖拽/翻面/自动/导出，移植为 `apps/web/components/holo/holo-sport-card.tsx` |
| `<sport>/web/assets/card.glb` | **要**：卡体模型（7 项运动 MD5 完全相同，只保留一份 `/holo/card.glb`） |
| `<sport>/web/assets/{subject,background,lineart}.png` | **要**：主体 / 背景 / 线描三层贴图，压成 WebP（1728×2368 → 1152 宽，质量 90），7 项合计 5.12MB |
| `<sport>/web/style.css`、`index.html` | **不要**：版式按我们自己的页面重做（Tailwind + RN 样式） |
| `<sport>/web/assets/text.png` | **不要**：印死的文字层 → 改成按档案数据实时 canvas 合成（否则卡面永远显示 demo 的战绩） |
| `index.html`/`gallery-*`/`build_*.py`/`sports.json`/`server.mjs`/`validate_glb.mjs`/`node_modules` | **不要**：gallery、批量生成脚本、本地服务、依赖副本 |

提取脚本：`scripts/build-holo-assets.mjs`（幂等，可重跑；输出 Web 1152 宽 / 移动端 896 宽两套）。
运动 key 映射：`football → soccer`、`tabletennis → table-tennis`，其余同名。

## 2. 数据（迁移 049）

`sports_profiles` 在 042 已有 `gear` / `highlights` / `level_text` / `play_style`，本轮补两层：

- **战绩**：`matches_played`、`wins`、`losses`（卡面右栏 + 分享页三格）；
- **绝技**：`signature_move`（卡面底部大字）。

口径（`computeSportsRecord`，shared 内唯一实现）：

- 场次 = `max(填写的场次, 胜 + 负)` —— 只填胜负时卡面不会显示「0 场」；
- 胜率 = `wins / matches`，保留一位小数；无场次返回 `null`（界面显示 `—`）；
- 负数 / 非法输入一律归零，服务端有 `CHECK (>= 0)` 兜底。

装备行按运动项目预填（`SPORT_GEAR_TEMPLATES`）：拍类刻意区分 **球拍型号 / 球拍类型 / 球鞋类型 / 拍线 / 磅数**，
乒乓球是底板 / 正手胶皮 / 反手胶皮，足球是球鞋（钉型）/ 球衣 / 护腿板……用户自己填值。

## 3. 卡面数据映射（`buildSportsCardModel`）

| 卡面位置 | 数据来源 |
| --- | --- |
| 顶部英文小标 | `SPORT_ARCHIVE_EN[sportKey]`（BADMINTON ARCHIVE…） |
| 大标题 | `<运动名>档案` |
| 标题下小字 | `<年份> 个人运动典藏` |
| 面板标题 | `运动员档案 · ATHLETE PROFILE` |
| 左栏 | `等级` + 最多 3 行装备（label/value） |
| 右栏 | 总战绩 / 胜 / 负 / 胜率 |
| 面板底部徽章 | `highlights`（赛事 + 成绩，最多 4 条） |
| 绝技上方小字 | `N 战 · M 胜 · 胜率 X%` |
| 绝技大字 | `signatureMove`（缺省回落 `playStyle`） |
| 左下 / 右下 | `NO.00X / 00Y`（档案序号）· HOLOGRAPHIC |

映射放在 `packages/shared`，**Web 三维卡与移动端拟态卡共用同一份内容**，两边不会写歪。

## 4. 双端实现

### Web（真 three.js，卡面文字实时合成）

- `apps/web/lib/holo-card-text.ts`：把源工程的 `text.png` 换成 canvas 版式（1728×2368 同尺寸），
  含面板高度随行数自适应、长文本省略、徽章按宽度换行；纯函数 `cardTextLayout()` 可单测。
- `apps/web/components/holo/holo-sport-card.tsx`：移植 app.js —— 顶点翻转 UV、三段着色器（正面镭射/侧面描金/背面描金「幻」）、
  `UnrealBloomPass` 泛光、拖拽转卡、滚轮缩放、F 翻面、R 复位、导出 PNG。
- 性能：three 与后处理走 `useEffect` 内动态 import（**异步 chunk**，构建已验证不在预渲染 HTML）；
  DPR ≤ 1.75、离屏 / 隐藏页暂停、`prefers-reduced-motion` 只画一帧、卸载 dispose、无 WebGL 回落 2D 静态卡。
- 入口：`/wellbeing/sports` 每张档案一个「查看闪光卡」弹层 + 战绩/绝技录入；`/share/sport/[slug]` 公开页顶部直接展示卡。

### 移动端（不跑 three.js：拟态闪光卡）

- `apps/mobile/src/components/sports-holo-card.tsx`：背景 + 主体两层贴图做视差，扫光条（主色 / 金 / 蓝）循环扫过模拟镭射，
  点按翻面（rotateY 620ms）看卡背（描金「幻」+ 典藏号），拖动倾斜回弹；worklet 只读写共享值。
- 信息按手机可读性重排：卡面只留「英文小标 / 标题 / 典藏 / 三项战绩 / 徽章 / 绝技 / 编号」，装备明细放在卡下方，
  避免把 1728 宽的版式等比缩到 340pt 导致不可读。
- 素材**随包发布**（`apps/mobile/assets/holo/`，7 项 3.32MB）而不是走网络：离线也能看卡。
- 入口：健康页「运动档案 → 运动闪光卡」→ `src/app/sports-card.tsx`（列表 + 建档/编辑 + 公开开关）。
