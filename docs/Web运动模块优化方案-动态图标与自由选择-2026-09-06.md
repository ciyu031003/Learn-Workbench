## 0. 现状盘点（决定了改造边界）

| 层 | 现状 | 结论 |
| --- | --- | --- |
| 数据库 | `exercise_logs.type` 枚举固定 6 类（BALL/AEROBIC/STRENGTH/STRETCH/MOVE/OTHER）+ `type_label` 自由文本(50字) + `source`(MANUAL/FOCUS/BREAK) + `client_id` 幂等；另有每类目标 `exercise_goal` | **无需迁移**：具体项目走 `type_label`，大类继续用 `type` |
| 后端 API | `POST /api/wellbeing/exercise` 已接受 `{type, typeLabel, durationSeconds, source}`；`GET` 汇总分钟数 | **无需改动**即可支持新项目；仅"今日记录列表"需小扩展（见 §5） |
| Web UI | 首页"一键运动"= 跳转 `/tasks?autofocus=exercise&minutes=30`（借专注计时）；健康页(wellbeing)有 6 类分段选择 + 时长 + 倒计时 + 目标，图标为 lucide 静态（Volleyball 等） | 本次改造主战场 |
| 移动端 | 已有 SportSheet：6 种运动 grid + 步进 + 快捷时长；`SportIcon` 选中动画（篮球弹跳旋转/羽毛球左右晃/散步摆动，reanimated）；记录存本地 store | 动画"词汇表"可直接对齐；记录暂未入库 exercise_logs（后续同步项，本次不动） |

## 1. 运动项目注册表（两层模型：大类 → 具体项目）

放在 `packages/shared`（单一事实源，Web/移动端共用）：

```ts
export interface SportItem {
  key: string;          // "basketball"
  name: string;         // "篮球"
  type: ExerciseType;   // 归属大类 → 对应 exercise_logs.type
  met: number;          // 运动强度系数（用于卡路里估算，见 §6）
  defaultMinutes: number;
}
```

**首批目录（19 项，覆盖你点名的全部项目）**：

| 大类 | 项目（met 值） |
| --- | --- |
| 球类 BALL | 篮球(6.5)、羽毛球(5.5)、排球(5.0)、乒乓球(4.0)、足球(7.0)、网球(5.0) |
| 有氧 AEROBIC | 跑步(8.0)、散步(3.5)、骑行(6.8)、跳绳(10.0)、游泳(7.0) |
| 力量 STRENGTH | 仰卧起坐(3.8)、深蹲(5.0)、俯卧撑(4.0)、平板支撑(3.3)、哑铃(3.5) |
| 拉伸 STRETCH | 拉伸放松(2.3)、瑜伽(2.5) |
| 日常 MOVE | 爬楼梯(8.0) |
| 兜底 OTHER | 自定义…（自由输入名称，写 type_label） |

- 兼容性：老记录 `type_label` 为空 → 显示大类名；新记录写具体项目名。**数据库零迁移、API 零改动**。
- 目录可扩展：后续加"飞盘/壁球/太极"只改注册表一行。

## 2. 交互设计

### 2.1 首页"一键运动" → "运动"弹窗（核心改动）
点击首页"一键运动"卡，弹出 GlassModal 运动面板（不再跳转专注页）：

```
┌─────────────────────────────────────────────┐
│  [球类] [有氧] [力量] [拉伸] [日常] [最近]     │  ← 分类 Tab，默认"最近"
│                                             │
│  🏀 篮球   🏸 羽毛球   🏐 排球   🏓 乒乓球   │  ← 项目网格（3~4 列）
│  ⚽ 足球   🎾 网球                          │     选中项图标"动起来"
│                                             │     hover 时轻微动一下
│  时长   [−] 30 分钟 [+]   [15][30][45][60]  │  ← 步进 + 快捷 chips
│                                             │
│  [▶ 开始计时]   [✓ 直接记录]                │  ← 双模式
│  最近：🏀篮球 30分 · 🏸羽毛球 15分 · 散步…   │  ← 最近 3 条（一键再记）
└─────────────────────────────────────────────┘
```

- **双模式**：
  - 「直接记录」：选好项目+时长，一步入库（快手路径，最常用）。
  - 「开始计时」：弹窗内原地进入倒计时（环形进度 + 暂停/放弃 + 完成自动入库，source=MANUAL）。**不再借用学习专注计时**，运动专注页保持纯粹。
- **「最近」Tab**：按最近使用排序的项目（取自 exercise_logs 最近 20 条的 distinct type_label），置顶 4 个可直接一键记录。
- 健康页（wellbeing）的运动模块换成同一个项目网格组件（复用），保留倒计时与目标设置，避免两套交互。

### 2.2 首页运动统计卡升级
- 「0 分 运动」卡：显示今日总分钟数 + **今日已练项目的小图标排**（如 🏀25' 🏸15'），点击直达弹窗。
- 「待记录」trackers 行的"运动 2/5"维持现有目标逻辑不变。

## 3. 动态图标方案（关键决策点）

**推荐：静态 SVG + CSS 动画**（每个项目一组专属 keyframes），而不是引入 Lottie：

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| **SVG + CSS 动画** | 零运行时依赖、体积小、动画节奏完全可控、跟随主题色、reduced-motion 易降级 | 动画表现力不如骨骼动画 | ✅ 主选 |
| Lottie（lottie-web + 现成动画） | 表现力最强（小人真的在跑） | +50KB 依赖；素材版权逐个核对；动图风格难统一 | 备选，不首推 |
| iconfont AEP 动效 | 阿里生态 | 需专用播放器、移动端不适配 | 不用 |

**素材来源**（阿里组件库方向）：
- 主源：**IconPark**（字节开源，Apache-2.0，可商用免署名）——"运动"分类下篮球/羽毛球/排球/乒乓球/足球/网球/跑步/走路/骑行/游泳/跳绳/哑铃/瑜伽/拉伸等全部有线性/填色两版，SVG 可直接内联；风格统一（同一线宽）。
- 补充：**iconfont.cn**（阿里组件库）搜"运动"彩色多色 SVG，选取风格一致的单个图标；下载后内联进组件（带来源注释）。
- 兜底：lucide-react 已装（Volleyball/Bike/PersonStanding 等），先用 lucide 占位、逐个替换为 IconPark 多色版。

**动画词汇表**（每个项目一段专属 CSS keyframes，全部只用 transform/opacity，选中循环播放，未选中静止；hover 轻微动 1 次；`prefers-reduced-motion` 时静止）：

| 项目 | 动画 |
| --- | --- |
| 篮球 | 弹跳：translateY 上下 + 触底挤压(squash) + 落点阴影同步缩放 |
| 羽毛球 | 左右晃动：rotate ±12° + translateX 摆动（像被球拍拨来拨去） |
| 排球/乒乓球 | 轻弹 + 微旋转 |
| 足球/网球 | 滚动旋转 + 小弹跳 |
| 跑步 | 小人整体颠簸（translateY 快速循环）+ 轻微前倾 rotate + 脚下速度线闪烁 |
| 散步 | 缓慢摇摆（rotate ±6° 慢循环） |
| 骑行 | 车身颠簸 + 轮组旋转（若 SVG 分组；否则整体颠簸） |
| 游泳 | 水平起伏（translateY/rotate 波浪节奏） |
| 跳绳 | 整体节拍跳跃 + 底部弧线扫动 |
| 仰卧起坐/俯卧撑/深蹲 | 垂直压缩节拍（scaleY 0.92↔1.06，模拟一起一落） |
| 平板支撑 | 轻微颤抖（translateX ±1px 高频） |
| 哑铃 | 提拉节奏（translateY + scaleY） |
| 瑜伽/拉伸 | 呼吸式缓胀缩（scale 0.98↔1.04，4s 慢循环） |
| 爬楼梯 | 上升位移循环（translateY -4px 阶梯跳） |

实现为一个 `<SportAnimatedIcon item={sportItem} active={boolean} size={n} />` 组件：内部查表拿 SVG + 动画类名；全局一份 keyframes 注入 globals.css。

## 4. 不做什么（避免范围膨胀）

- 不做 GPS 轨迹/地图（FitTrackee 领域，超出工作台定位）。
- 不做训练计划/动作视频库（wger 领域，重）。
- 不做重量组数记录（Hevy 领域）；力量类只记时长，行为一致。
- 移动端记录入库 exercise_logs（双端数据打通）**另起一轮**，本次仅 Web。

## 5. 后端/API 的小改动（唯一一处）

- `GET /api/wellbeing/exercise`：返回今日记录列表（含 type_label/duration/startedAt），用于首页统计卡的项目图标排 + 弹窗"最近"Tab。其余接口零改动。

| Keep/Hevy 类商业产品交互 | 首页"最近使用"快捷重记 | ✅ "最近"Tab 一键重记（成本极低、频次最高） |
