构造规则：每个字符是一棵只有根的树，权值为其频度；反复取森林中权值最小的两棵树合并（新根权值 = 两子树根权值之和），直到森林只剩一棵树。n 个叶子的哈夫曼树共 2n−1 个结点，没有度为 1 的结点。
为什么 WPL 最小：WPL = Σwᵢlᵢ。贪心每次把最小的两个权值放到最深的位置，等价于让频度大的字符离根更近；由交换论证可知任何最优树都含"最小两权值互为兄弟且最深"的结构，所以每步贪心都不会错过最优解（典型贪心算法）。
前缀码：任一编码都不是另一编码的前缀。哈夫曼树的字符只出现在叶子上，从根读一位走一步，落到叶子即确定一个字符，译码无歧义。平均码长 = WPL / Σwᵢ；等长编码需 ⌈log₂n⌉ 位，频度分布越不均，哈夫曼编码优势越大。
